# Results

Generated by the scripts in `experiments/`. Re-run with `make experiments`; the hierarchical files additionally require `make hierarchical` (PyMC 5 environment) and `make hier_compare`.

| File | Generated by | Contents |
|---|---|---|
| `recovery.npz` / `.csv` / `.json` | `experiments/recovery.py` | 100 datasets × 500 trials; true and estimated `v, a, w, t0`; metrics. |
| `euler_recovery.npz` / `.csv` / `.json` | `experiments/euler_recovery.py` | Independent Euler–Maruyama recovery check (100 datasets × 500 trials; seed 77). |
| `density_validation.json` | `experiments/validate_density.py` | Float32 vs float64 WFPT log-density error and small-time truncation check (seed 123). |
| `benchmark.csv` | `experiments/benchmark.py` | CPU float64/float32 and MPS float32 density/MLE timings. |
| `empirical_roitman.csv` / `.json` | `experiments/empirical_roitman.py` | Roitman & Shadlen (2002) fits with ddmtorch and PyDDM. |
| `empirical_roitman_psychometric.csv` | `experiments/empirical_roitman.py` | Observed and predicted psychometric functions. |
| `contaminant_check.json` | `experiments/contaminant_check.py` | Illustrative no-mixture vs 5% mixture recovery under contaminants. |
| `empirical_bootstrap.json` / `_samples.csv` | `experiments/bootstrap_empirical.py` | 500 trial-level bootstrap resamples per monkey; percentile intervals. |
| `empirical_rt_quantiles.csv` | `experiments/empirical_rt_quantiles.py` | Observed vs predicted RT quantiles (0.1–0.9) by monkey, coherence, and choice. |
| `hierarchical_cavanagh.json` / `_subject.csv` / `_summary.csv` | `experiments/hierarchical_pymc.py` | PyMC 5 HDDM-style hierarchical fit on the 14-subject Cavanagh et al. (2011) dataset (4 chains, 1,000 draws/tune, seed 2026). |
| `hierarchical_comparison.json` / `_mle.csv` / `_merged.csv` | `experiments/hierarchical_compare.py` | ddmtorch MLE vs hierarchical posterior means. |

Figures are written to `paper/figures/` by `experiments/make_figures.py`.

The main numbers reported in `paper/main.tex` are:

- Recovery (100 × 500): RMSE `v=0.097`, `a=0.034`, `w=0.018`, `t0=0.007`; correlations `0.996, 0.995, 0.981, 0.998`.
- Euler check (100 × 500): RMSE `v=0.101`, `a=0.049`, `w=0.018`, `t0=0.007`; biases `v=+0.0004`, `a=+0.033`, `w=+0.001`, `t0=+0.002`.
- Density: max abs log error `3.5e-5` (CPU32) / `3.1e-5` (MPS32) for `tau >= 0.02`.
- Benchmark: 1M-trial density fwd+bwd `3.21 s` (CPU64), `1.22 s` (CPU32), `0.62 s` (MPS); 50k-trial / 20-subject MLE `7.30 s`, `4.10 s`, `2.32 s`.
- Empirical (monkey 1): ddmtorch `beta=10.494, a=1.489, w=0.488, t0=0.307, NLL=204.30`; PyDDM `beta=10.536, a=1.486, w=0.483, t0=0.309, NLL=206.66`.
- Empirical (monkey 2): ddmtorch `beta=9.495, a=1.749, w=0.501, t0=0.193, NLL=1254.22`; PyDDM `beta=9.602, a=1.754, w=0.494, t0=0.194, NLL=1254.61`.
- Bootstrap 95% CIs (monkey 1): beta [10.050, 11.048], a [1.458, 1.511], w [0.479, 0.498], t0 [0.301, 0.319]; monkey 2: beta [9.158, 9.939], a [1.726, 1.770], w [0.491, 0.511], t0 [0.189, 0.198].
- RT quantile check: 100 observed/predicted quantile points; RMSE 0.165 s. The model over-disperses at low coherence and predicts too-slow high-coherence tails; this is model misfit, not an implementation difference.
- Hierarchical comparison (14 subjects): correlations `v_LL=0.997`, `v_WL=0.9995`, `v_WW=0.997`, `a=0.999`, `t0=0.996`; RMSE `0.065, 0.032, 0.074, 0.015, 0.009`; expected shrinkage in v and t0.
